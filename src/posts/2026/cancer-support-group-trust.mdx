**病友支持群組是癌友重要資源——同伴感、實用建議、心理支持。但也是健康詐騙、保健食品多層次傳銷、療效誇大訊息的高發地。** 本文整理「值得加入」的特徵、「該離開」的 8 個紅旗、保健食品傳銷的典型運作模式、被詐騙後的通報管道，與如何幫助家人辨識可信來源。

<Callout type="note" title="閱讀對象">
本文設定讀者為剛診斷或治療中的癌友與家屬，正在尋找或評估病友群組。實際個案如遇詐騙請依本文通報；本文不取代法律與心理諮詢。
</Callout>

<Divider />

## 好群組 vs. 紅旗群組對照

| 好群組特徵 | 紅旗特徵 |
|---|---|
| 由醫療專業、合格基金會運作 | 匿名管理員、頻換暱稱 |
| 不推銷商品、課程、線下講座 | 推銷保健食品、課程、療癒營 |
| 資訊有可查證來源（NCCN、醫院） | 「美國臨床證實」「祖傳祕方」 |
| 尊重個人治療選擇 | 公開批評他人選擇 |
| 鼓勵與主治醫師討論 | 誘導停西醫 |
| 隱私保密 | 公開或私訊要求醫療資料 |
| 免費（或基金會收象徵性費用） | VIP / 進階收費 |
| 多元意見 | 一言堂、不能提問 |

| 組織 | 範圍 | 服務 |
|---|---|---|
| **財團法人癌症希望基金會** | 全癌 | 急難救助、心理支持、家屬支持、衛教 |

| **台灣肺癌學會** | 肺癌 | 衛教、研討 |
| **台灣血液病友聯誼會** | 血癌 | 病友支持 |
| **各醫學中心病友會** | 院內 | 與主治團隊合作 |

**特徵**：合法立案、財務透明、有醫療顧問、不推銷商品。

## 8 大紅旗（立刻離開）

| 紅旗 | 為什麼 |
|---|---|
| 1. 「我用 XX 治好了癌症」+ 推銷產品 | 個案故事 ≠ 證據；多為行銷話術 |
| 2. 拉下線拿傭金 | 多層次傳銷，多為非法食品宣稱療效 |
| 3. 「百分百能治癒」絕對宣稱 | 醫療法 §87 違反；無任何藥物能 100% 治癒 |
| 4. 誘導停西醫 | 危險，多人因此延誤治療 |
| 5. 不知成分的「家傳祕方、藥粉、藥膏」 | 摻偽、重金屬、西藥污染 |
| 6. 收費 VIP 群、進階課程 | 商業變現，多無實質醫療價值 |
| 7. 私訊要醫療資料、身分證、銀行帳號 | 詐騙標準手法 |
| 8. 管理員身分不明、頻換暱稱 | 信用無法查證 |

## 保健食品傳銷的典型運作

<Steps>
  <div>
    ### 階段 1 — 建立信任

    管理員自稱「癌友」、分享「治癒故事」、貼合理衛教文章降低戒心。
  </div>
  <div>
    ### 階段 2 — 置入產品

    「我吃了 XX 後體力好很多」、「我推薦 XX」、「我醫師也建議我吃」。
  </div>
  <div>
    ### 階段 3 — 拉下線

    「加入會員享折扣」、「介紹朋友拿傭金」、「上線拿被動收入」。
  </div>
  <div>
    ### 階段 4 — 建立緊迫感

    「限時優惠」、「即將漲價」、「最後一批」。
  </div>
  <div>
    ### 階段 5 — 誇大療效

    「臨床試驗證實」（多假造或斷章取義）、「FDA 認證」（食品 GRAS ≠ 藥物核准）。
  </div>
</Steps>

**辨識**：要求拉下線 → 違反《多層次傳銷管理法》、《藥事法》、《食安法》。

## 「過於熱心」的私訊

特別小心**陌生人或剛認識的「病友」私訊**：

| 私訊內容 | 警覺度 |
|---|---|
| 「我也是 XX 癌，加油」（純鼓勵） | 低（多為善意） |
| 「我用 XX 好很多，分享給你」 | 中（檢視是否推銷） |
| 「我介紹一個醫師 / 老師 / 大師」 | 高（多為直銷） |
| 「我有便宜的藥源 / 進口管道」 | 高（多為非法購藥 / 詐騙） |
| 「我加你 LINE 詳談 / 給你帳號匯款」 | **極高，立刻封鎖** |

## 通報管道

| 詐騙類型 | 通報 |
|---|---|
| 保健食品療效詐騙 | 衛福部食藥署 **1919**；地方衛生局 |
| 藥事法違規 | 食藥署 1919；地方衛生局 |
| 多層次傳銷 | **公平交易委員會** |
| 消費糾紛 | 消保官 **1950** |
| 金錢詐騙 | **165 反詐騙**、報警 |
| 醫療廣告違規 | 地方衛生局醫政科 |
| 醫療業務招徠（醫療法 §87） | 地方衛生局醫政科 |
| LINE 詐騙 | 165 + LINE 內檢舉 |
| Facebook 詐騙 | 165 + 檢舉廣告 |

## 已經買了 / 被詐騙的應對

<Steps>
  <div>
    ### 第一步 — 停損

    立刻停止購買、停止拉下線、停止傳訊息給其他病友。
  </div>
  <div>
    ### 第二步 — 保留證據

    截圖對話、保留收據、產品包裝、轉帳紀錄。
  </div>
  <div>
    ### 第三步 — 通報

    依詐騙類型撥打對應專線（見上表）。
  </div>
  <div>
    ### 第四步 — 告知主治醫師

    被推銷的「保健食品 / 藥膏」可能與治療衝突，需評估。
  </div>
  <div>
    ### 第五步 — 心理支持

    被詐騙不是「太傻」。詐騙者專業操作信任、絕望、希望。需要時尋求心理諮商。
  </div>
  <div>
    ### 第六步 — 警示家人朋友

    避免家人朋友被同方式詐騙。
  </div>
</Steps>

## 幫助長輩家人辨識可信來源

| 重點 | 怎麼做 |
|---|---|
| **預先教育** | 在診斷初期就跟家人介紹合法基金會 |
| **設定家庭共識** | 「任何花錢的健康決定都先全家討論」 |
| **集中諮詢窗口** | 一個家人專責整理「該問醫師的問題」 |
| **建立可信來源清單** | 醫院個管師、護理師、衛教手冊、合法基金會網站 |
| **檢視長輩 LINE 群組** | 定期關心、警示明顯詐騙 |

## 適用對象 / 不適用對象

### 本文適用
- 剛診斷的癌友與家屬，正在尋找支持資源
- 想協助長輩家人辨識詐騙者
- 第一線個案管理師、社工師、家醫科衛教

### 本文不適用
- 取代法律諮詢（重大金錢糾紛）
- 取代心理諮商（被詐騙後創傷）

## 風險揭露

本文整理一般原則。**個別個案請依專業法律與心理協助**。詐騙手法不斷演變，需保持警覺。
