# 06 飲食、生活與保健（10 題）

最常被「養生 / 民俗」誤導的領域。本分類重點是「給證據等級」（A/B/C/D 或 NCCN integrative oncology level）而不是回答「能不能吃」。

---

### 79. 化療期間能不能吃生魚片、生菜？感染風險證據怎麼看

- **titleEn**: Neutropenic diet: evidence and what's actually risky
- **Slug**: `neutropenic-diet-evidence`
- **Patient query**: 「化療能吃生魚片嗎？」「生菜不能吃？」
- **差異化**：「neutropenic diet 沒有效果」研究（DeMille 2006、Trifilio 2012）+ 真正該避免的食物清單
- **關鍵字**：neutropenic diet、food safety、衛教

### 80. 癌症病人吃糖會餵養腫瘤嗎？

- **titleEn**: Does sugar feed cancer? Evidence vs myth
- **Slug**: `does-sugar-feed-cancer`
- **Patient query**: 「癌症病人不能吃糖？」「果糖比較毒？」
- **差異化**：Warburg effect 真實意義 + insulin / IGF-1 訊號 + 過度限糖反而體重不足風險
- **關鍵字**：sugar、cancer、Warburg、衛教

### 86. 預防癌症的「10 招」哪些是真的有效？實證版

- **titleEn**: Cancer prevention: which "10 tips" are actually evidence-based?
- **Slug**: `cancer-prevention-evidence-graded`
- **Patient query**: 「不抽菸不喝酒就不會得癌症嗎？」「常吃花椰菜可以防癌？」
- **差異化（實證反超）**：
  - 競品（網路文 / 保健品行銷）給「10 種防癌食物 / 飲食關鍵」之類的廣告化清單，幾乎不附證據等級
  - 本篇直接拿 IARC Code Against Cancer (2024)、WCRF/AICR Continuous Update Project、USPSTF (2024) 三個權威來源並列，逐項標 evidence level（convincing / probable / limited / no link）
  - 區分「人口層級」防癌建議 vs「個人」防癌建議的不同（很多競品搞混 RR vs ARR）
  - 直接列出「沒有實證」的迷思（鹼性飲食、斷食抗癌、特定保健食品防癌）
- **關鍵字**：cancer prevention、IARC、WCRF、USPSTF、evidence-based
